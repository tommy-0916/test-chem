## 本轮判定口径

- `stage_task_requirements_v1` 记录从原始任务推得的样品臂与比较关系；缺一组不算当前 Stage 覆盖。
- `stage_observation_protocol_v1` 记录受控工作站 Skill 的协议 ID、来源摘要和入站要求。若样品状态、容器或体积未定，保持 `runtime_pending` 并给出 Device resolver 路径。
- `stage_action_queue_v1` 绑定每臂 route、实验组、sample、action 和物料图摘要；即使首臂 Research 发布，也只标记 `partially_published/not_executed`。
- 后续任一门失败时，以状态文件中首个发生的 blocker、reason code 与实际样品臂覆盖为结果。`goal_reached=false` 不能改写成实验成功。
