# 暗箱拍摄工作站_V1

## 操作 1. **暗箱光照流程** 通过暗箱拍摄照片

### 输入输出约束
  - **输入约束**
    - 容器类型：96位塑料孔板或96位石英孔板
    - 容器状态：无盖
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：无盖
    - 样品状态：与输入保持一致
