# 谱学容器中转平台_V1

## 操作 1. **容器中转** 容器中转

### 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或液相54孔板或50ml耐热瓶或西林瓶或96位石英孔板或96位塑料孔板或气相54孔板
    - 容器状态：必须无盖
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致

### 参数设置
*以下表格中，参数名前的"-"代表层级关系，需结合"-"个数判断参数之间的关系层级
- **容器中转**

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 进样瓶或液相54孔板或50ml耐热瓶或西林瓶或96位石英孔板或96位塑料孔板 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 进样瓶最小0个最大10个;液相54孔板最小0个最大1个;50ml耐热瓶最小0个最大10个;西林瓶最小0个最大10个;96位石英孔板最小0个最大1个;96位塑料孔板最小0个最大1个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量 |  |
