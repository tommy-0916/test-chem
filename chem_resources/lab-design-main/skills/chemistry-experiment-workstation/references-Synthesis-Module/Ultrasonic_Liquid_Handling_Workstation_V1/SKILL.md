# 超声移液平台_V1

## 操作 1. **超声加液流程** 启动超声加液

### 输入输出约束
  - **输入约束**
    - 容器类型：96位塑料孔板或96位石英孔板
    - 容器状态：不限
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：与输入保持一致
    - 样品状态：分散均匀的悬浊液或纯液态

### 参数设置
*以下表格中，参数名前的"-"代表层级关系，需结合"-"个数判断参数之间的关系层级
- **超声加液流程**

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 96位塑料孔板或96位石英孔板 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 96位塑料孔板最小0个最大2个;96位石英孔板最小0个最大2个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量 |  |
| 配置参数 | 加液配置参数 | 是 |  | object |  |  |
| -加液配置 | 具体加液信息 | 是 |  | object |  |  |
| --孔板编号 | 孔板编号 | 是 |  | string |  |  |
| --参数文件 | 加液文件参数 | 是 |  | file |  |  |

- 类型为`file`的参数构建如下：
1. **读取模板文件**：`references_file/Ultrasonic_Liquid_Handling_Workstation_V1_参数文件模板.csv`
2. **根据需求更改文件**：
基于模板文件自动生成实验传参文件，上传的文件名 **《Ultrasonic_Liquid_Handling_Workstation_V1_参数文件.csv》** ，只刷新加液参数列，所有参数严格遵循约束规则。
- 修改部分：第二列~第五列
- 孔位编号（第 1 列）：表示 96 孔板加样孔位编号；模板文件中已预置孔位，严格保留原值，不得修改、删除、重排或重复。
- 原液瓶加液量列（第2 列起）：分别对应不同编号原液瓶的加液量，单位均为 μL，每列取值范围均为 [0, 500]。
- 原液瓶类型数量限制：单文件内最多只允许使用 4 种不同原液瓶类型，即加液列总数最多对应 4 个原液瓶。不得新增列。
- 单孔总体积限制：每个孔位所在行的所有原液瓶加液量之和 不得超过 500 μL。
- 空白列约束：除明确允许刷新的加液量列外，其他列、表头、格式均不得修改。
- 若某孔位未使用某种原液瓶，则对应单元格填写 0。
- 文件名称和文件类型：保持不变。
- 表头和第一列保持不变。
3. **上传文件并获取文件路径**：将文件作为`file_path`传入，执行命令：`python scripts\upload2obs.py "{{file_path}}"`，获取返回的文件路径。最终输出的json格式方案中包括此文件路径。
