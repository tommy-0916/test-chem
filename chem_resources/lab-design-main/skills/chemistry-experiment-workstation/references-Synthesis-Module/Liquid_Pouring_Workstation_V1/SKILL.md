# 液体倾倒工作站_V1

## 操作 1. **开盖**

### 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶
    - 容器状态：有盖
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：无盖
    - 样品状态：与输入保持一致

| 参数名      | 备注                                   | 是否必填 | 单位 | 类型     | 示例值                                                     | 默认值 |

| 容器类型     | 指定需获取的容器类型                           | 是    |    | string | 进样瓶                                                   |     |
| 容器数量     | 指定需获取的容器数量                           | 是    |    | int    | 进样瓶最小0个最大10个                                           |     |
| 容器编号     | 指定需获取的容器编号                           | 是    |    | array  | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量)       |     |
| 开盖瓶号    | 开盖瓶号                                | 是    |    | array  |                                                         |     |
| -瓶号      | 瓶号                                   | 是    |    | string |                                                         |     |
| 保留瓶盖      | 是否保留瓶盖 | 是 | | int | | [{"label":"是","value":"1"},{"label":"否","value":"0"}] |
