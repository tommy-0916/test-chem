# 烘干机_V1

## 操作

- **烘干主流程** 烘干

## 输入输出约束

  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶
    - 容器状态：不限
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：与输入保持一致
    - 样品状态：与输入保持一致

- **烘干主流程**
