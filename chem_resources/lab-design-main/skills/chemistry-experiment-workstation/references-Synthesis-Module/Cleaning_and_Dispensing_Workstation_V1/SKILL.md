# 批量加液工作站_V1

## 操作 1. **批量加液流程** 批量加液流程

### 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶
    - 容器状态：无盖
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：有盖
    - 样品状态：与输入保持一致
