# 耐热瓶物料站

## 整体流程约束
输出容器为耐热瓶时，后续必须接移液平台或多通道固体称量或单通道固体称量工作站。

## 操作

## 输入输出约束

- **容器拿取**
  - **输入约束**
    - 容器类型：50ml耐热瓶
    - 容器状态：有盖
    - 样品状态：必须无样品状态
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：与输入保持一致
    - 样品状态：必须无样品状态

## 参数设置

- **容器拿取**

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 50ml耐热瓶 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 50ml耐热瓶最小1个最大50个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量 |  |
