# 多通道固体称量工作站_V1

## 相似工作站的区别
> Multi_Channel_Solid_Weighing_Workstation_V1,多通道固体称量工作站_V1：多样品并行固体称量、筛选实验或多通道配方固体加入场景，最多支持30种固体样品的添加。

> Multi_Channel_Solid_Weighing_Workstation_V2，多通道固体称量工作站_V2：多样品并行固体称量、筛选实验或多通道配方固体加入场景，最多支持10种固体样品的添加，容器类型为10ml耐压反应管。
> Single_Channel_Solid_Weighing_Workstation_V1，单通道固体称量工作站_V1：对单个样品通道进行单种固体样品的高精度定量称量与进样


## 操作

- **固体进样-文件传参-机器人** 通过文件下发称量固体

## 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或西林瓶或50ml耐热瓶
    - 容器状态：必须无盖
    - 样品状态：必须无溶液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：粉末

## 参数设置

- **固体进样-文件传参-机器人**

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 进样瓶或西林瓶或50ml耐热瓶 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 进样瓶最小0个最大20个;西林瓶最小0个最大10个;50ml耐热瓶最小0个最大10个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量 |  |

1. **读取模板文件**：`references_file/Multi_Channel_Solid_Weighing_Workstation_V2_固体进样文件传参模板.xlsx 自动生成实验传参文件`。
2. **根据方案生成文件**：基于模板文件生成新文件，只刷新第 2 列、第 3 列，所有参数严格遵循约束规则。
强约束规则：
- 瓶号（第 1 列）：自动从 1 开始连续编号，总行数 = 容器数量，瓶号与容器数量完全一致；
- 加样量（第 2 列）：单位为g，取值范围为[0,50]；
- 料罐号（第 3 列）：单文件内料罐号全局统一，取值范围为[1,30]，具体数值可自行选取；
- 文件类型：保持不变
- 表头和第一列保持不变。
3. **上传文件**：将生成的文件作为`file_path`传入，执行命令：`python scripts\upload2obs.py "{{file_path}}"`
