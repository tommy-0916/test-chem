# 智能光催容器中转平台_V1

## 说明
96位塑料孔板或96位石英孔板默认都不带盖子。

## 操作 1. **光催化压膜转运至中转位_96位孔板** 仅适用于前工作站为"光照压膜工作站"，操作为"氢气检测膜压膜后光照流程"的96位孔板转运至智能光催化中转位

### 输入输出约束
  - **输入约束**
    - 容器类型：96位塑料孔板或96位石英孔板
    - 容器状态：必须无盖
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致

### 参数设置
*以下表格中，参数名前的"-"代表层级关系，需结合"-"个数判断参数之间的关系层级

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 96位塑料孔板或96位石英孔板 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 96位塑料孔板最小0个最大1个;96位石英孔板最小0个最大1个 |  |
