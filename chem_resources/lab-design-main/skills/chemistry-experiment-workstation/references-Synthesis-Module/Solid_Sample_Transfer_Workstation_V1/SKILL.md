# 固体样品转移工作站_V1

## 操作 1. **固体样品转移**

### 输入输出约束
  - **输入约束**
    - 容器类型：96位塑料孔板或50ml耐热瓶或西林瓶或进样瓶
    - 容器状态：无盖
    - 样品状态：固体
  - **输出约束**
    - 容器类型：料斗
    - 容器状态：无盖
    - 样品状态：固体

### 参数设置

| 参数名      | 备注                                   | 是否必填 | 单位 | 类型     | 示例值                                                     | 默认值 |
|----------|--------------------------------------|------|----|--------|---------------------------------------------------------|-----|
| 容器类型     | 指定需获取的容器类型                           | 是    |    | string | 料斗或96位塑料孔板或50ml耐热瓶或西林瓶或进样瓶 |     |
| 容器数量     | 指定需获取的容器数量                           | 是    |    | int    | 料斗最小0个最大10个;96位塑料孔板最小0个最大1个;50ml耐热瓶最小0个最大10个;西林瓶最小0个最大10个;进样瓶最小0个最大10个 |     |
| 容器编号     | 指定需获取的容器编号                           | 是    |    | array  | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量)       |     |
