# 纯化工作站_V1

## 相似工作站的区别

> Centrifuge_V1,离心机_V1:容器类型：进样瓶
> Purification_Workstation_V1,纯化工作站_V1:容器类型：进样瓶或留样瓶

## 操作

- **纯化离心** 离心纯化流程

## 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或留样瓶
    - 容器状态：必须有盖且数量为1-10之间的偶数
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须有盖
    - 样品状态：悬浊液或纯液态或固体
