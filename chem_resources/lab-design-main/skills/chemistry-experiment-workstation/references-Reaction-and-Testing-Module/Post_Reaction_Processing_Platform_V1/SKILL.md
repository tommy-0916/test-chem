# 反应后处理平台_V1

## 操作 1. **后处理**

### 输入输出约束
  - **输入约束**
    - 容器类型：10ml耐压反应管
    - 容器状态：无盖
    - 样品状态：悬浊液
  - **输出约束**
    - 容器类型：液相54孔板或96位塑料孔板或气相54孔板
    - 容器状态：与输入保持一致
    - 样品状态：纯液态

### 参数设置

| 参数名      | 备注                                   | 是否必填 | 单位 | 类型     | 示例值                                                     | 默认值 |
|----------|--------------------------------------|------|----|--------|---------------------------------------------------------|-----|
| 容器类型     | 指定需获取的容器类型                           | 是    |    | string | 10ml耐压反应管                                                |     |
| 容器数量     | 指定需获取的容器数量                           | 是    |    | int    | 10ml耐压反应管最小0个最大4个                                           |     |
| 容器编号     | 指定需获取的容器编号                           | 是    |    | array  | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量)       |     |
