# 液相色谱仪_V1

## 整体流程约束
前置工作站：进入该工作前，需要有谱学置物工作站

## 操作 1. **液相分析**

### 输入输出约束
  - **输入约束**
    - 容器类型：液相54孔板
    - 容器状态：无盖
    - 样品状态：纯液态
  - **输出约束**
    - 容器类型：液相54孔板
    - 容器状态：无盖
    - 样品状态：与输入保持一致

### 参数设置

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 液相54孔板 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 液相54孔板最小1个最大100个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量) |  |
| 新建方法 | 新建方法文件参数 | 是 |  | file |  |  |
| 开始分析行号 | 开始分析行号 | 是 |  | int |  |  |
| BatchFile | 构建文件参数上传 | 是 |  | file |  |  |

- 类型为`file`的参数构建如下：
1. **读取模板文件**：references_file目录下`Liquid__Chromatograph_V1_BatchFile模板文件.json`,`Liquid__Chromatograph_V1_新建方法文件模板文件.json`
2. **根据需求更改文件**：
  (1)新建方法:`Liquid_Chromatograph_V1_新建方法文件模板文件`无需修改，直接上传，上传的文件名 **《Liquid__Chromatograph_V1_新建方法文件.json》**。
  (2)BatchFile: 基于模板文件 `Liquid_Chromatograph_V1_BatchFile模板文件.json` 自动生成色谱采样 batchfile，上传的文件名 **《Liquid__Chromatograph_V1_BatchFile.json》**
该文件用于指定：对哪些样品瓶进行采样、每个样品的进样体积，以及对应的数据保存文件名。

修改部分：BatchDatas 中每一对象的VialNo、Injvol、DataFileName三个参数
BatchDatas数组中的每一个对象对应一个待采样样品。
VialNo：进样瓶编号，例如 "1" 表示对色谱进样瓶 1 采样
Injvol：进样体积，单位为 μL，例如 5 表示进样体积为 5 微升
DataFileName：数据保存文件名，例如 "0" 表示该样品结果保存为文件名 0

强约束规则：
- 只允许修改以下 3 个参数：VialNo、Injvol、DataFileName。
- 其他所有参数均不得修改，必须与模板保持完全一致。
- 不得修改 JSON 结构、字段名称、字段顺序不得新增、删除或重排无关字段。
- BatchDatas 中每个对象对应一个样品采样任务。
- 文件名称和文件类型：保持不变。
- 表头和第一列保持不变。



3. **上传文件并获取文件路径**：将文件作为`file_path`传入，执行命令：`python scripts\upload2obs.py "{{file_path}}"`，获取返回的文件路径。最终输出的json格式方案中包括此文件路径
