# 红外光谱仪_V1

## 整体流程约束
- 前置工作站：进入该工作前，需要有谱学置物和谱学磁力搅拌
- 测试溶液不得少于4ml。

## 操作

- **谱学红外流程-夹具识别** 红外光谱检测流程
## 输入输出约束

  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶
    - 容器状态：必须无盖
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致
