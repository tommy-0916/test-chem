# 光照压膜工作站_V1

## 操作 1. **氢气检测膜压膜后光照流程** 压膜后光照

### 输入输出约束
  - **输入约束**
    - 容器类型：96位塑料孔板或96位石英孔板
    - 容器状态：必须无盖
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：96位塑料孔板
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致

### 参数设置
*以下表格中，参数名前的"-"代表层级关系，需结合"-"个数判断参数之间的关系层级
- **氢气检测膜压膜后光照流程**

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 96位塑料孔板或96位石英孔板 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 96位塑料孔板最小0个最大1个;96位石英孔板最小0个最大1个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量 |  |
| 孔板编号 | 孔板编号 | 是 |  | string |  |  |
| 光催化文件 | 光催化参数文件 | 是 |  | file |  |  |
