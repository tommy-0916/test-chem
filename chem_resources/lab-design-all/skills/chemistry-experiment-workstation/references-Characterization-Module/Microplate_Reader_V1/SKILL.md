# 酶标仪_V1

## 操作 1. **酶标仪303谱学流程** 使用酶标仪高通量测试试剂紫外光谱

### 输入输出约束
  - **输入约束**
    - 容器类型：96位塑料孔板或96位石英孔板
    - 容器状态：必须无盖
    - 样品状态：纯液态
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致
