# 荧光光谱仪_V1

## 整体流程约束
前置工作站：进入该工作前，需要有谱学置物工作站

## 操作

- **荧光光谱进样绘图** 开始荧光光谱测试

## 输入输出约束

  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶
    - 容器状态：必须无盖
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致
