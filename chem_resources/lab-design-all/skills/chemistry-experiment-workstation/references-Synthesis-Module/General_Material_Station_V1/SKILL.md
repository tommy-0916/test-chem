# 常规物料站

## 整体流程约束
输出容器为进样瓶时，后续必须接移液平台或多通道固体称量或单通道固体称量工作站。

## 操作

- **物料拿取** 物料拿取

## 输入输出约束

  - **输入约束**
    - 容器类型：进样瓶或西林瓶
    - 容器状态：有盖
    - 样品状态：必须无样品状态
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：与输入保持一致
    - 样品状态：必须无样品状态

## 参数设置

- **物料拿取**

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 进样瓶或西林瓶 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 进样瓶最小0个最大60个;西林瓶最小0个最大10个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号，如`[1,2]`，表示拿取该容器类型的1号和2号容器。**注意：容器编号相对于容器类型独立，每个容器类型的容器编号均从1开始编号，不可以跨容器类型编号**，进样瓶编号范围1-60，西林瓶编号范围1-10 |  |
