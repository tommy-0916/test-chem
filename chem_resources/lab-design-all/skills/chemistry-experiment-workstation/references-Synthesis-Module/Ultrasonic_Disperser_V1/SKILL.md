# 超声分散仪_V1

## 相似工作站的区别

> Ultrasonic_Disperser_V1,超声分散仪_V1:容器类型为进样瓶或50ml耐热瓶
> Ultrasonic_Disperser_V2,超声分散仪_V2:容器类型为进样瓶或50ml耐热瓶或西林瓶

## 操作

- **超声清洗** 超声清洗

## 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶
    - 容器状态：不限
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：与输入保持一致
    - 样品状态：分散均匀的悬浊液或纯液态
