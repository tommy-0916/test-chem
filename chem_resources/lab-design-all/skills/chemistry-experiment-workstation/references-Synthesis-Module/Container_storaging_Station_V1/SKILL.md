# 容器置放平台_V1

## 操作 1. **静置**

### 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶或西林瓶
    - 容器状态：不限
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：与输入保持一致
    - 样品状态：与输入保持一致

### 参数设置

| 参数名 | 备注 | 是否必填 | 单位 | 类型 | 示例值 | 默认值 |
|--------|----------|----------|------|------|--------|--------|
| 容器类型 | 指定需获取的容器类型 | 是 |  | string | 进样瓶或50ml耐热瓶或西林瓶 |  |
| 容器数量 | 指定需获取的容器数量 | 是 |  | int | 进样瓶最小0个最大10个;50ml耐热瓶最小0个最大10个;西林瓶最小0个最大10个 |  |
| 容器编号 | 指定需获取的容器编号 | 是 |  | array | 指定需获取的容器编号(如`[1,2]`，表示拿取1号和2号容器，最大值不超过容器数量 |  |
| 静置时间 | 静置时间 | 是 | min | int |  | 86400 |
