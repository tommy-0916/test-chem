# 移液平台_5ml_V3

## 工作站id约束
2350309661279232

## 整体流程约束
- 向目标反应容器（10ml耐压反应管）中加入指定液体
- 适用于在合成、洗涤、稀释、重分散及其他较大体积液体处理流程中，向目标容器加入溶剂、洗涤液或其他指定液体时使用
- 最多支持加入8种不同类型的溶液
- 移液枪单次转移最大溶液量为1mL，适用于每种溶液加入量不超过3mL

## 输入输出约束

- **反应管加样**
  - **输入约束**
    - 容器类型：10ml耐压反应管
    - 容器状态：无盖
    - 样品状态：不限
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：无盖
    - 样品状态：纯液态或悬浊液
