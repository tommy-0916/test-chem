## 整体流程约束
- 前置工作站：进入该工作前，需要有谱学置物和谱学磁力搅拌。
- **[强约束] 测试溶液体积校验**：进入该工作站前，容器内样品总液量（Total Liquid Volume）必须 ≥ 4.0ml。若设计方案中各组分加和不足4ml，必须在加液步骤（如移液平台）中通过增加溶剂或等比例放大前驱体体积进行补齐。
- **[自动化执行逻辑] 龙虾在生成步骤时须遵循以下分支**：
    - **分支 A：若前置步骤产物为【液体/悬浊液】且体积 < 4.0 mL**
      - 策略：通过去到移液平台增加“无水乙醇”作为分散溶剂，补足至 4.0 mL。
    - **分支 B：若前置步骤产物为【固体粉末】**
      - 策略：**必须**在进入XRD站之前，增加移液平台的加液步骤，加入 **4.0 mL 无水乙醇**，并配合“磁力搅拌”将其转化为均匀悬浊液。
    - **分支 C：若实验设计要求保持高浓度**
      - 策略：等比例放大所有前驱体投料量，使反应后总体积 ≥ 4.0 mL。

## 输入输出约束
  - **输入约束**
    - 容器类型：进样瓶或50ml耐热瓶
    - 容器状态：必须无盖
    - 样品状态：纯液态或悬浊液
  - **输出约束**
    - 容器类型：与输入保持一致
    - 容器状态：必须无盖
    - 样品状态：与输入保持一致
